# Sources

Every number or claim in the product or the pitch needs a source here. If it isn't here, it doesn't go on a slide.

## How to add a source

```
- **Claim:** what we say
  - **Source:** [Title](URL), date accessed
  - **Notes:** context, caveats
```

## EU Taxonomy

- [EU taxonomy for sustainable activities](https://finance.ec.europa.eu/sustainable-finance/tools-and-standards/eu-taxonomy-sustainable-activities_en), European Commission
  - **Notes:** what the Taxonomy is, the six objectives, legislation and timeline. Page updated March 2026.
- [EU Taxonomy Navigator](https://ec.europa.eu/sustainable-finance-taxonomy/), European Commission
  - **Notes:** home of the Taxonomy Compass (activities, objectives, criteria; Excel and JSON downloads), the calculator, FAQs and user guide.
- [Taxonomy Regulation (EU) 2020/852](https://eur-lex.europa.eu/legal-content/EN/TXT/?uri=CELEX:32020R0852), EUR-Lex
  - **Notes:** the legal basis, including the four conditions for an activity to be environmentally sustainable.
